# Instrument sample attribution

The sampled instrument audio in this directory is derived from the 21-key
instrument resources under `instruments/` in:

- Project: VanillaNahida/WindsongLyre-Sim
- Source: https://github.com/VanillaNahida/WindsongLyre-Sim
- Revision: c4be9fb018067fb9d43607db538923ac89421924
- License declared by the source repository: GNU GPL version 3

The Windsong Lyre source directory contains one reference sample. Its 21 files
are pitch-shifted derivatives for the natural-note keyboard layout. All other
instrument files are renamed from the source's 0-20 key-index layout without
altering their audio content.

See `GPL-3.0.txt` in this directory for the source repository's license text.
