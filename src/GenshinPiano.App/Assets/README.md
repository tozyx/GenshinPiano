# Windows icon assets

`Brand/GenshinPiano-master.png` is the transparent 1254 px source artwork.
Run `tools/generate_windows_icons.py` to rebuild all derived assets.

`Icons/GenshinPiano.ico` contains 16, 20, 24, 30, 32, 36, 40, 48, 60,
64, 72, 80, 96, 128, and 256 px frames for Win32 and WPF.

`Package/` contains app-list target-size assets, light/dark unplated variants,
square logo sets, Windows 10 tile sets, and Microsoft Store logo sets. Scale
assets cover 100%, 125%, 150%, 200%, 250%, 300%, and 400%.

Microsoft references:

- https://learn.microsoft.com/windows/apps/design/iconography/app-icon-design
- https://learn.microsoft.com/windows/apps/design/iconography/app-icon-construction
