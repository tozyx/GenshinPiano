# SMT 扫描谱第一轮优化与验证

日期：2026-11-11。范围：稳健切行、异常校验、局部重识别。本轮落地在独立 SMT 试验流程，尚未切换应用的 OCR 后端；图像处理仍使用开发期 Python，模型推理为原生 CPU。

当前支持范围已收敛为清晰、平直的扫描谱和电子谱截图。拍照谱适配及自动几何矫正已按用户要求放弃，保留漏切检测和明确失败提示。

后续 [拍照谱测试](SMT_PHOTO_ROBUSTNESS.md) 发现并补上了局部谱表覆盖检查，防止弯曲页面只切出部分谱行却被接受；新增回归后共 18 项测试通过。扫描谱输入文件保持不变，下文为第一轮优化时的测量结果。

## 结果

沿用同一张《稻香》的清晰、模糊扫描图及整页 17 小节、243 个发声音符的参考，评分口径见 [SMT/Oemer 对照](OCR_SMT_OEMER_COMPARISON.md)。本次重新运行的十条基线输出与上轮逐字节一致。

- **清晰图**：完整音符 F1 从 **98.97% → 99.18%**。完整匹配仍为 241/243，但多余尾音消失，输出从 244 个音符减少到 243。音高序列编辑数从 1 降为 0；首行拍号从错误的 3/4 变为 4/4，全小节休止也变为正确的 4 拍，12 个书写休止全部匹配。
- **模糊图**：完整音符 F1 从 **96.52% → 98.57%**。完整匹配从 236/243 提高到 241/243，输出音符数仍为 246；音高序列编辑数从 5 降为 3。重复声部尚未完全解决，不将它们直接删除。
- 两图都只重试了 **2/5 行**。清晰图额外运行 4 个候选，模糊图额外运行 6 个候选；每个异常行最多重试三次。
- 实际优化流程总耗时分别 **27.333 秒、33.238 秒**。同次运行中，初次五行推理合计分别 15.429、14.442 秒，加入重试后的推理合计分别 26.390、32.604 秒。总耗时还包含解压、布局检测和图像准备；速度与准确度存在明确取舍。

这是同一张谱的两种分辨率，参数也曾在此谱上试验，没有独立留出集。参考标注未由独立标注者复核；结果不能推断其他扫描谱的通用准确率。

## 切行改动

此前按整页横线数量是否为十的倍数判断，额外横线或漏线可能让整页失败。现在按局部五条近似等距谱线发现谱表，通过上下谱表间的竖向小节线连接验证配对：

- 忽略不构成谱表的独立横线，降低横向覆盖阈值以检测较短的末行。
- 在其他完整谱表已提供间距依据时，最多推断某个谱表的一条缺失横线，并记录推断数量。
- 检测到可信的未配对谱表时拒绝静默省略，提示检查布局。
- 从图像竖线得到每行预期小节数，末尾双小节线合并为一个边界；不读取参考答案的小节数量。
- 两张真实图均检测到五组上下谱表，图像得出的小节数量均为 3、3、4、4、3。初次处理图像像素及原生输出保持与原基线相同。

实现见 [布局检测](../tools/ocr/smt_scan_layout.py) 和 [图像准备](../tools/ocr/prepare_smt_scan.py)。目前仍限于近水平、单钢琴、带可验证竖向连接的扫描谱。

## 校验与选择规则

[校验器](../tools/ocr/smt_scan_quality.py) 只使用模型输出和图像布局：

1. 检查退出码、超时、空输出、截断、谱表结构及输出小节数量。
2. 从多个谱表/小节时值的多数一致结果推断可信拍长；不默认所有谱都是 4/4。显式且自洽的变拍号、原有弱起/不完整末小节保留。
3. 记录超拍、缺拍、拍号冲突、未闭合延音和疑似重复声部。全空记录仅作诊断，不作为必须重试或删音符的理由。
4. 候选复用基线中可信的拍长与弱起信息，不能通过自行改变拍长、产生“无法校验”的结果来获得更高排名。
5. 同小节同谱表同起点、时值、音高的重复事件视为可疑，但不自动删除。真实复调也可能触发检查，因此这里只用于重试与提示。

排名为固定的透明加权异常分，越低越好：无法解析/后端失败 10000；小节数差 1000/个；非全空行的结构错误 100/个；时值异常 20/处加拍长差绝对值的 10 倍；拍号冲突 15/处；延音异常、疑似重复各 10/处；无法验证拍长的小节 25/个。它是重试启发式，不是准确率、模型置信度或通过验收的证明。

## 局部重识别

[流水线](../tools/ocr/optimize_smt_scan.py) 首次仍使用谱线间距 8 像素、浅色水印抑制。只在出现异常的行按固定顺序尝试：

1. 间距 9 像素，保留水印抑制。
2. 间距 8 像素，保留原始灰度。
3. 间距 7 像素，保留水印抑制。

每个候选保留原始符号、stderr、耗时、输入哈希和校验结果。无异常时提前停止；否则选异常分最低的可接受候选，同分保留基线。**若候选改变了基线中未发现异常的小节，拒绝该候选**，防止整行重试破坏原本正常的部分。发生小节数量异常时，小节索引不再可信，整行标为可疑。

本次选择：

- 清晰图第一行选择 9 像素版本，第五行选择 7 像素版本，其余保留基线。
- 模糊图第三行选择保留原始灰度的 8 像素版本，第五行选择 7 像素版本，其余保留基线。第三行仍有时值、延音、重复声部异常，报告明确标为未解决。

候选选择没有读取音高标注或曲名，也没有强行补拍、改拍号或删尾音。拍号、休止与尾音的改善来自重新识别得到的原始输出。

## 首次方案失败与修正

最初版本允许候选自行推断拍长。清晰图改善，但模糊图退步到 F1 90.08%：部分节奏已改变的候选无法形成多数拍长，却被当作无异常。该次输出完整保留在 round1-clear、round1-blur，未作为最终结果。

修正为“基线可信拍长固定、未知不等于通过、未异常小节保护”，并增加回归测试。最终结果来自新运行的 round1-v2-clear、round1-v2-blur，而非从所有候选中按参考分数挑选。

## 尚未解决

- 清晰图第 11 小节的两处 E5 节奏错误仍存在。这些输出的总拍数、结构均自洽，当前规则无法发现，因此该行没有重试。
- 模糊图第 8 小节仍有重复声部和局部时值错误，第 11 小节仍多出一个低音 B3。第三行已提示异常，第四行的多音本身结构自洽，尚无可靠自动判据。
- 清晰图显示“无剩余规则异常”不代表全部音符正确，必须与最终离线评分区分。

## 验证和复跑

已通过 **17 项单元测试**，覆盖额外横线、短末行、缺一条谱线、未配对谱表、末尾双线、真实 3/4、变拍号、弱起、候选拍长逃逸、未异常小节保护、重复音保留、截断和同分保留基线。另验证真实原生进程 1 秒超时后退出且无残留进程。

SMT 事件读取抽到 [共享解析模块](../tools/ocr/smt_notation.py)，供校验与离线评分复用。原 SMT/Oemer 四组整页基线结果在提取前后完全一致，前六小节评分也保持不变。

开发 Python 需 Pillow、NumPy。CPU ZIP 放在 publish/smt-experiment，单系统模型允许位于该目录或 models 子目录，均校验固定 SHA-256。

```powershell
# 输出目录每次必须是新目录，避免覆盖证据。
python tools/ocr/optimize_smt_scan.py `
  publish/smt-experiment/inputs/0011877-w-b-1.png `
  publish/smt-experiment/results/replay-clear

python tools/ocr/optimize_smt_scan.py `
  publish/smt-experiment/inputs/clipboard_20261111_105629.png `
  publish/smt-experiment/results/replay-blur

# 识别、盲选完成之后，才将参考提供给单独的离线评分程序。
python tools/ocr/evaluate_smt_scan_optimization.py `
  publish/smt-experiment/results/replay-clear/report.json `
  publish/smt-experiment/results/replay-blur/report.json `
  --output publish/smt-experiment/results/replay-evaluation.json

python -m unittest discover -s tools/ocr -p test_smt_scan_pipeline.py -v
```

最终证据：publish/smt-experiment/results/round1-v2-clear、round1-v2-blur、round1-v2-evaluation.json；每行 selection.json 记录所有候选、拒绝原因、最终选择和未解决状态。
